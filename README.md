# Gates of Hell Research Tree

Explore the dynamic-conquest research trees from **Call to Arms: Gates of Hell —
Ostfront**, using data extracted from the installed game and Steam Workshop mods.

[Open the viewer](https://ggvw.github.io/GatesOfHellResearchTree/) ·
[Download a release](https://github.com/ggvw/GatesOfHellResearchTree/releases) ·
[Viewer guide](docs/viewer-guide.md)

## Main features

- Interactive research graph and mobile-friendly unit table.
- Search and filters for units, weapons, equipment, armour, and firing range.
- Detailed unit statistics, weapon comparisons, armour values, and turret speeds.
- Research prerequisites, CP, RP, and total research costs.
- Automatic Workshop mod detection, with separate vanilla and single-mod views.
- Offline HTML viewer with game images, localized names, and light/dark themes.
